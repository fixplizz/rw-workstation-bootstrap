Release Candidate · v0.1.0-rc7

Your Ubuntu workstation, ready.

Install a consistent development, DevOps, AI, daily work, and remote-access setup on Ubuntu 26.04 Desktop amd64.

Run as your regular user

bash -c 'set -o pipefail; curl -fsSL --retry 3 --retry-all-errors https://fixplizz.github.io/install | bash'

The installer requests sudo only for system operations.

Requirements

  • Ubuntu 26.04 Desktop amd64
  • Regular user with sudo
  • Internet connection
  • GNOME on Wayland recommended

A practical workstation baseline

Fixplizz installs ordered, resumable modules and records each run in JSON with a complete log.

Development

Node.js LTS with npm, pnpm, Yarn, TypeScript, lint/test tools, plus Python, Go, Rust, and selectable extra runtimes.

DevOps

Docker, kubectl, Helm, k9s, OpenTofu, Ansible, SOPS, Trivy, Gitleaks, and Hadolint.

AI and daily work

Orca desktop agent IDE, Codex CLI, OpenCode CLI, Hermes Agent, herdr dashboard, Obsidian, Zen Browser, LocalSend, LibreOffice, FFmpeg, and Poppler.

Desktop and remote

Guarded GNOME defaults, Alacritty, Starship, NetBird, RustDesk, and Termix.

System changes: the script installs system packages and applications. Review the public repository before running it on a machine you need to preserve.

Continue or add runtimes

Resume an interrupted installation, or open the optional runtime menu at any time.

fixplizz resume · fixplizz runtime menu
