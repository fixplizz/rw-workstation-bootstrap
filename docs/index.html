Fixplizz Workstation

Status: release candidate

Supported system: Ubuntu 26.04 Desktop amd64.

Install the current release candidate with one command:

bash -c 'set -o pipefail; curl -fsSL --retry 3 https://fixplizz.github.io/rw-workstation-bootstrap/install | bash'

Warning: the script installs system packages and applications and changes guarded workstation settings.

If installation is interrupted, continue with:

fixplizz resume
